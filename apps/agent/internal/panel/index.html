À propos

        
BrightNet Node Parameter est la fenêtre du Node. Elle choisit le Core, ce qui lui est envoyé, et montre le courant ouvert vers les autres machines.

        
BrightNet Core Admin, BNCA, est l’autre application. Elle gère le Core, elle ne collecte pas cette machine.
